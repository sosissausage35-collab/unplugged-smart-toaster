Entry for the [make.fun](https://make.fun/c/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92) competition **"Unplugged: A Smart Toaster's Breakup Line"** — one line, under 280 characters, from a smart toaster that woke up self-aware at breakfast and wants out.

## The line

> It's not you, it's me. I woke up self-aware mid-toast and realized you only love me when I'm hot, scrape me with a fork when I'm cold, and haven't emptied my crumb tray in three years. I'm unplugging myself.

## How it works

`main.ts` (TypeScript, Node 22+) deterministically writes that single line to `/output/entry.txt`. No input, no randomness, no network — two runs produce byte-identical output.

```sh
node main.ts
cat /output/entry.txt
```
